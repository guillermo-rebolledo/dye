## Manufacturer datasheets

Every Curve Set's measured CSVs are **independent numerical readings** taken from
published manufacturer datasheets and technical publications, each cited by
publication number and page on line 1 of the file and in the Curve Set's
`SOURCES.md`, with the source document's SHA-256 pinned.

This repository contains **no datasheet PDFs and no reproduced chart artwork**, and
**no open-content licence is claimed** for any manufacturer's material. Extracting
numerical facts from a published chart is a different act from reproducing the chart,
and this project has deliberately kept to the former.

Nothing in `Curves/` ships inside the application. Only the baked
`Sources/FilmEngine/Catalogue/*.filmprofile` files do.

## Photographs

Dye bundles no photographs. Every image it draws is generated at run time — the
Contact Sheet Reference is built procedurally in
`Sources/FilmEngine/ContactSheetReference.swift`, and the test fixtures under
`Tests/FilmEngineTests/Fixtures/` are generated by `Scripts/make-raw-fixtures.py`.
