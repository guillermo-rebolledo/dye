Requirements live in the Linear `dye` project in the Memoji Inc workspace:
https://linear.app/memoji-inc/project/dye-08b875851eb4/issues

Use the connected Linear `get_issue` tool with identifiers from commit messages
(e.g. MEM-240). MEM-239 is the parent specification. `CONTEXT.md` is the canonical
domain glossary. Tests assert at the Profile codec, renderer entry point, and
Baker CLI boundaries defined in that specification.
